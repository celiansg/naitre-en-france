# Roadmap

## Livré dans le MVP

- [x] Verticale naissance → vie → choix → fin → bilan.
- [x] 29 scènes d'événements et 20 décisions dans le moteur.
- [x] PRNG seedé et sauvegarde locale versionnée.
- [x] Mode doux, reduced-motion, navigation clavier et textes alternatifs.
- [x] Pages sources, méthodologie, confidentialité et accessibilité.
- [x] Tests de déterminisme, pondération relative, choix et raccourci jusqu'à la prochaine décision.
- [x] Parcours Playwright desktop et mobile : naissance, provenance, clavier, sauvegarde et exploration.

## Prochaine itération

- [ ] Pipeline d'import CSV/JSON validé par Zod avec rapport de calibration Monte Carlo.
- [ ] Données INSEE sur les naissances vivantes par département et année, métropole + DROM.
- [ ] Données compatibles avec la pauvreté des familles avec enfants et conditionnement explicite.
- [ ] Distributions France par niveau de vie, logement, études, emploi, santé et mortalité.
- [ ] 80+ événements, 50+ décisions et contexte historique sourcé avec règles d'impact séparées.
- [ ] Test de concurrence si un serveur est introduit.
- [ ] Export JSON / suppression de sauvegarde et carte de partage exportable.

## Hors périmètre volontaire

Pas de classement moral, de vote attribué au personnage, d'inférence religieuse/ethnique/politique, de diagnostic médical ou de prédiction individuelle.
