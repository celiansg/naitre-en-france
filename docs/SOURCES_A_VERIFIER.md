# Sources à intégrer et vérifier avant publication
- INSEE — bilan démographique et naissances : https://www.insee.fr
- INSEE — pauvreté, niveau de vie, Filosofi : https://www.insee.fr
- DREES — santé et protection sociale : https://drees.solidarites-sante.gouv.fr
- DEPP — école : https://www.education.gouv.fr/depp
- DARES — emploi : https://dares.travail-emploi.gouv.fr
- INED — démographie : https://www.ined.fr
- Données électorales officielles : https://www.data.gouv.fr

Vérifier millésime, champ, dénominateur, géographie, méthode, licence, confidentialité, conditionnements et ruptures de séries. Ne pas confondre pauvreté nationale de tous les individus avec probabilité de naître dans un foyer pauvre.
